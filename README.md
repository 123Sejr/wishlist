# Wishlist

En webapplikation, hvor brugere skal kunne oprette og dele ønskesedler. 

## Features

Planlagte:
- Opret din ønskeseddel og tilføj ønsker
- Del din ønskeseddel med andre
- Reservér ønsker på andres ønskesedler

## Teknologi
- Java
- Spring Boot
- Thymeleaf
- JDBCtemplate
- MySQL
