# Contributing to Wishlist
Tak fordi du viser interesse og bidrager til Wishlist projektet.

## Kom godt i gang
1. Fork repository'et eller opret en ny branch.
2. Hent projektet til din computer.
3. Åben projektet i IntelliJ.
4. Sørg for at projektet kan bygges og startes.

## Arbejdsproces
1. Opret et Issue i GitHub på Projektet "wishlist".
   - Giv den passende navn og eventuelt uddybende beskrivelse.
   - Tildelt den en prioritet (har den høj eller lav prioritet).
2. Tildel dig selv til opgaven.
3. Opret en branch fra delevop-branch med passende navn.
4. Dokumenter processen med kommentarer.
5. Test den implementeret løsning.
6. Commit ændringerne
7. Push til Github.
8. Opret et Pull Request.
   
## Coding Standards
- Brug meningsfulde variabelnavne og metodenavne.
- Følg Java naming conventions.
  - **Classes** skrives i PascalCase med et beskrivende og meningsfuldt navn.
  - **Metoder** skrives i camelCase.
  - **Variabler** skrives i camelCase og holdes kort.
- Dokumenter koden med kommentarer, der forklarer kodens funktionalitet og logik.
- Undgå duplikeret kode  

## Commit beskeder
Brug meningsfulde commit-beskeder.

## Testing
Før der oprettes Pull Request:

- Projektet skal kunne buildes.
- Projektet skal kunne startes.
- Nye funktioner skal være testet.
